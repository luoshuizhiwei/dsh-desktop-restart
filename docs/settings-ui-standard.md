# 设置页界面统一规范（本插件）

2026-11-13 首次定稿，2026-11-22 按当前实现重写。
起因：设置页各行样式不统一（有的卡片、有的分隔线、按钮三种变体混用），看着乱；
后来又出现「为了统一而忽略所在容器」的反向错误，所以补了第三条。

## 一、只有三种行型

| 行型 | 类名 | 何时用 | 结构 |
| --- | --- | --- | --- |
| **标准行** | `.dshdr-set-row` | 一个设置项：开关、或「输入框 + 保存」 | 左：标签(14/500) + 说明(12/三级色)；右：控件。行间 `.5px` 分隔线，上下 `16px` |
| **内容行** | `.dshdr-set-row` + `.dshdr-sweep-row` | 要展示明细/列表的项 | 说明与列表占满宽度，操作按钮在下一行左对齐 |
| **折叠区** | `.dshdr-health-fold` | 一组密度高的次级内容（Cookie 健康、遗留快照） | 见第三节 |

**禁止**：卡片套卡片、给个别行单独加边框/底色/圆角。

## 二、字号只有四档，行高固定 1.5 倍

| 用途 | 字号 / 行高 | 字重 | 颜色 token |
| --- | --- | --- | --- |
| 辅助文字（提示、状态、时间戳） | **12 / 18** | 400 | `--dsw-alias-label-tertiary` |
| 正文（行标签、按钮、入口名） | **14 / 22** | 500（标签）/ 400（按钮） | `--dsw-alias-label-primary` |
| 区块标题 | **16 / 24** | 600 | `--dsw-alias-label-primary` |
| 关键数字（Cookie 用量） | **20 / 28** | 700 | `--dsw-alias-label-primary` |

**不再有 13px 这一档**（2026-11-19 并入 12px）：夹在 12 和 14 之间既不够醒目也不够低调。

## 三、折叠区：标题行 + 开关，不用 `<details>`

2026-11-17 起，折叠区不再用 `<details>/<summary>`（默认展开会占掉半屏），改成：

```
[标题] [徽章] ────────── [数字] [开关]     ← .dshdr-health-head
[3px 细进度条，仅折叠时显示]                ← .dshdr-health-mini
[展开区：明细、选项、按钮]                  ← .dshdr-cookie-detail
```

硬要求：
- **默认折叠**，只显示横条；开关决定展开（偏好存 localStorage，两个区各一个 key）。
- 「数字 + 开关」包在 `.dshdr-health-tail` 里整块靠右 —— **两个折叠区的开关必须左右对齐**。
- 折叠时明细里不能有"只有展开才看得到"的异常：摘要自己要说清「扫描中 / 状态无法读取（红） / 上次扫描失败（橙）」。
- 超限等安全状态**强制展开**，不受开关控制。

## 四、间距只有六级

`4 / 8 / 12 / 16 / 24 / 32`（px）

| 级别 | 用在哪 |
| --- | --- |
| 4 | 图标与文字、徽章内、紧凑列表项 |
| 8 | 相邻控件（开关与按钮） |
| 12 | 同一区块内的行与行 |
| 16 | 区块与区块、行的上下内边距 |
| 24 / 32 | 事实行之间的列间距 |

## 五、图标尺寸：跟随所在容器，不搞全局统一

**这是 2026-11-22 的教训**：为了"统一"把图标全改成 16px，结果在官方容器里比邻居大一圈。

| 位置 | 尺寸 | 依据 |
| --- | --- | --- |
| 会话标题栏 | **12** | 实测官方「PTC 模式」「子智能体」「后台任务」三个都是 12 |
| 侧栏底部动作行 | **14** | 官方动作行图标 |
| 侧栏面板项 | 跟随座位传入的 `size`，**内缩 2px** | 官方传 16（展开）/ 18（收起）；我们的刷新环占满画布，同尺寸会显得更大 |
| 账号菜单项 | **14** | 官方菜单图标视觉更小，16 会压过「设置」的齿轮 |
| 我们自己的面板 / 设置页 | **16** | 自己的地盘，用自己的标准 |

**原则**：官方容器有官方规范时，跟随官方；只有在我们自己画的容器里才用本插件标准。

## 六、按钮只有三种变体

| 变体 | 用在哪 | 例子 |
| --- | --- | --- |
| `primary` | 每个视图最多 1 个，破坏性主操作 | 面板「重启」 |
| `outline` | 次级但需要看得见的独立动作 | 保存倒计时、清空已读诊断、标记已读 |
| `ghost` | 工具栏 / 行内轻操作 | 刷新状态 |

硬要求：
- **不许**覆盖按钮的底色与文字色（2026-11-13 踩过：写死白字配浅色主题 = 白底白字）。
- **宽度不随文案跳动**：状态在「重启 ↔ 确认重启 ↔ 仍要重启?」之间切换，主按钮设 `min-width`（面板 148px、标题栏 92px）。

## 七、状态与颜色

- 结果行统一用 `.dshdr-set-result` + `data-tone`（ok / warn / error），带 `aria-live=polite`。
- 同一件事只出现一次：手动操作后结果行已经说过，就不再重复「上次…」那句。
- 能删除的功能，说明文字必须写出「默认只预览 / 开启后才会删」。
- **同一个语义只用一个 fallback 色**：错误色统一 `#ec1313`（2026-11-22 之前混用了 `#f85149`，主题变量缺失时会看到两种红）。
- 确认态（即将做破坏性操作）一律用危险色，不管它在侧栏底部、标题栏还是设置页。

## 八、改完自检清单

1. 新增行是否直接复用 `.dshdr-set-row`？有没有自造边框/底色？
2. 按钮是否只用了 primary / outline / ghost？有没有硬编码颜色？
3. 字号是否只用了 12/14/16/20 四档，行高是否 1.5 倍？
4. 间距是否只用 4/8/12/16/24/32？
5. 图标尺寸是否跟随所在容器，而不是套用全局值？
6. 同一信息是否在两处重复出现？
7. `npm run lint` 与 `npm test` 是否都过？
