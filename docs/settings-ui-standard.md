# 设置页界面统一规范（本插件）

2026-11-13 定。起因：设置页里各行样式不统一（有的卡片、有的分隔线、按钮三种变体混用），看着乱。
数值对齐官方 `docs/official-ui-standard.md`（Button md = H36 / `--dsw-radius-md` / padding 0 14px；Button sm = H28 / 12px 字）。

## 一、只有三种行型，不许再自造第四种

| 行型 | 类名 | 何时用 | 结构 |
| --- | --- | --- | --- |
| **标准行** | `.dshdr-set-row` | 一个设置项：开关、或「输入框 + 保存」 | 左：标签(14/500) + 说明(12/三级色)；右：控件。行间 `.5px` 分隔线，上下 `16px` |
| **内容行** | `.dshdr-set-row` + `.dshdr-sweep-row` | 要展示明细/列表的项（如快照候选） | 说明与列表占满宽度，操作按钮在**下一行左对齐** |
| **折叠块** | `.dshdr-health-fold` | 一组密度高的次级内容（如 Cookie 健康） | `<details>` 折叠；展开后内部仍用标准行，不画卡片 |

**禁止**：卡片套卡片、给个别行单独加边框/底色/圆角。

**折叠块的硬要求**：summary 里只放「标题 + 一句话概览」（如「15 个候选 · 0.5 MB」），
明细、列表、按钮全部放进展开区；同一分组里凡是密集内容都必须是折叠块，不许有的大开着、有的收着。

## 二、字体与间距（只允许这几档）

| 用途 | 字号 / 字重 / 行高 | 颜色 token |
| --- | --- | --- |
| 分区标题（h3） | 14 / 500 / 22 | `--dsw-alias-label-primary` |
| 行标签 | 14 / 500 / 22 | `--dsw-alias-label-primary` |
| 行说明 | 12 / 400 / 18 | `--dsw-alias-label-tertiary` |
| 关键数字（如用量） | 20 / 700 / 28 | `--dsw-alias-label-primary` |
| 列表项 | 12 / 400 / 18 | 名称次级色、数值三级色 |

间距只有 `16px`（行）、`12px`（行内 gap）、`8px`（紧凑组）、`4px`（列表项间）。

## 三、按钮只有三种用法

| 变体 | 用在哪 | 例子 |
| --- | --- | --- |
| `primary` | **最终动作 / 需要强调** | 清理候选「确认删除？」状态 |
| `outline` | 行内次要动作 | 保存倒计时、保存有效时间、立即扫描预览、清理候选（未武装） |
| `ghost` | 仅工具栏/标题栏等无底色场景 | 标题栏重启、面板内刷新 |

**不许**覆盖按钮的底色与文字色（2026-11-13 踩过：写死白字配浅色主题 = 白底白字）。

## 四、状态回执

- 结果行统一用 `.dshdr-set-result` + `data-tone`（ok / warn / error），带 `aria-live=polite`。
- 同一件事只出现一次：手动操作后结果行已经说过，就不再重复「上次…」那句。
- 能删除的功能，说明文字必须写出「默认只预览 / 开启后才会删」，不允许两处说法矛盾。

## 五、改完自检清单

1. 新增行是否直接复用 `.dshdr-set-row`？有没有自造边框/底色？
2. 按钮是否只用了 primary / outline / ghost 三种？有没有硬编码颜色？
3. 字号是否只用了 14/500、12/400、20/700 三档？
4. 同一信息是否在两处重复出现？
5. `npm run lint` 与 `npm test` 是否都过？
