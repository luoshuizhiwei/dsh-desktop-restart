# 0.4.6

## 修复

- **等待中主按钮点了没反应**：等待/倒计时/暂停期间主按钮现在明确禁用并显示「已锁定」，
  点击不再落入「第一次静默武装确认、第二次直接重启」的路径。常规出口是旁边的「取消等待」。
- **标题栏点击无反馈**：宽屏下也会显示状态文字（确认重启？／仍要重启？／已锁定），
  并按状态改变颜色。此前宽屏只有图标，点第一下看不出任何变化。
- **红色警告不会消失**：有任务时的「仍要重启？」现在 15 秒后自动撤销，
  可在设置里改成 5–60 秒。此前会一直挂着，离开后误碰一次就重启。
- **面板出现两个「刷新状态」**：执行期间「状态重试」按钮与常驻「刷新」按钮文案重复，
  已改为只在状态读取真的失败时才出现。
- **账号菜单重启项首次打开不显示**：此前要开关两次才出现。
  真实原因是菜单在点击回调执行前就已提交进页面，只订阅「后续变更」的观察器永远等不到；
  现改为点击时立即探测，观察器仅作兜底。
- **账号菜单重启项位置跳动**：改为锚定菜单内容容器最前，并在绘制前完成插入。
- **悬停按钮时文字闪烁**：悬停会触发一次状态读取，期间「刷新状态」变成「稍等…」并变半透明。
  现在悬停走后台读取（仍更新守卫信息），不再改变按钮文案与禁用外观；显式点击刷新保留加载反馈。
- **重启执行期间出现重复按钮**、**helper 启动失败未被捕获**、**插件停用后入口复活**、
  **旧确认定时器干扰新一轮警告**、**设置保存无超时导致控件永久禁用**：均已修复。
- **op 记录读取失败会用空对象覆盖原文件**（可能导致 profile 被永久锁定）；
  **关键写入失败不记录日志**（失败路径静默丢失）。现读失败不覆盖、写失败必记日志。

## 安全性

- 认证 Cookie 检查改为**只读统计 + 可选备份**，**不再自动删除任何 Cookie**。
  数据库始终只读打开，备份保留最近 3 份；超限时给出手动处理指引。
- Cookie 检查移入独立线程，8 秒预算后终止并等线程退出，避免数据库卡住时拖住重启。
- 跨进程重启锁（原子创建 + 陈旧锁接管），避免两个实例同时结束同一主进程。
- 日志与交接记录中的可执行文件路径改为只记文件名，启动参数值脱敏。
- 平台鉴权服务不可用时，写路由返回 503 而不是放行。

## 变更

- 有任务在跑时，主按钮第二击直接强制重启（跳过等待与倒计时），
  不再保留独立的「仍要立即重启」按钮；危险操作使用官方危险色。
- 标题栏的「刷新」按钮改为可配置，**默认关闭**。
- 快照扫描只保留预览，移除不可达的删除能力；界面不再显示「已删除/释放空间」。
- 移除设置页内部的「账号菜单诊断」块（开发者调试信息）。
- Cookie 检查时间显示为本地时间。

## 工程

- 引入 ESLint 与 CI lint 步骤。
- npm 包瘦身：只发布运行时文件（9 个文件，此前 22 个）。
- 测试：新增行为契约用例；保留的源码文本断言单独登记并标注「非行为验收」，
  不再计入行为覆盖；`npm test` 共 smoke 119 / client 191 / opt02 7。

## 已知边界

- 账号菜单入口依赖宿主菜单 DOM 结构，结构变化时会静默跳过（不破坏原菜单）。
- 读屏软件、逐帧视觉、菜单键盘导航、多窗口并发、各主题与窄屏像素布局尚未验收。
- Cookie 健康检查要求 Node.js ≥ 22.16（`node:sqlite`），低版本自动跳过该功能。
