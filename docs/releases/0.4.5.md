# 0.4.5

## 新增

- 重启阶段与失败原因可见；重启完成后显示「宿主已于 HH:MM:SS 完成重启（停机 N 秒）」。
- **默认先等空闲**：有任务在跑时排队等待，任务结束自动重启；`/restart-desktop --now` 或
  界面上的「仍要立即重启」立即执行。
- 扫描改为只预览不删除，并显示候选数、大小、跳过原因、早筛计数与错误码。

## 移除

- 自动续跑整体移除（v4 消息来源格式不兼容，投递会失败）。

## 安全性

- helper 身份核验（PID/父 PID/创建时间/路径）；参数读不出拒绝执行；端口归属不明中止；
  记录缺失时标为结果未知且不放行。
